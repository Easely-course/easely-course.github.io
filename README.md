# שלום כיתה א׳ – הקורס המוגן

האתר: https://heavyfocus-art.github.io/shalom-kita-a/

- `index.html` – מסך הכניסה עם הקוד האישי של הקונה.
- `enc/` – תוכן הקורס **מוצפן** (AES-256-GCM). בלי קוד תקף אי אפשר לפתוח אותו.
- `sw.js` – פותח את התוכן רק במכשיר שיש בו רישיון תקף.
- `guard.js` – בודק בתוך הקורס שהרישיון עדיין בתוקף.
- `config.js` – הכתובת של גיליון Google שמנהל את הקונים.
- `tools/Code.gs` – הקוד של הגיליון (בלי המפתח – המפתח נמצא רק בגיליון של המוכר).
- `tools/build.js` – מצפין את הקורס: `node tools/build.js <תיקיית הקורס> <קובץ המפתח>`.

כל קוד ננעל על המכשיר הראשון שבו נכנסים, ובתוקף 30 יום מהכניסה הראשונה.
